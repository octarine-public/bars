# Unit bars
- [x] Display health and mana bars of enemy heroes
- [x] Shown where the game hides its own bar: in the fog, mid-teleport, tossed or cycloned
- [x] Drawn the way the game draws its own, with the hero's icon and level beside the bar
- [x] The numbers are set in the game's own numeric face, its digits all one width so a reading holds still as it ticks; font, size, weight and outline are yours to change, and the mana bar grows to hold its reading
- [x] The numbers switch off per bar, from the section header or with a click on the preview
- [x] The numbers can also stand over enemies the game keeps its own bar on, without a bar of ours
- [x] A live preview in the menu shows the bars the way the game will draw them
- [x] Support for heroes, bears and other controllable units

# Полосы юнитов
- [x] Отображение полос здоровья и маны вражеских героев
- [x] Показываются там, где игра прячет свою полосу: в тумане, во время телепорта, в подбросе или циклоне
- [x] Рисуются как родные полосы игры, с иконкой и уровнем героя по бокам
- [x] Цифры набраны числовым шрифтом самой игры: все цифры одной ширины, поэтому число не дёргается при тиках; шрифт, размер, толщина и обводка настраиваются, полоса маны растёт под своё число
- [x] Цифры отключаются для каждой полосы отдельно: в заголовке секции или кликом по предпросмотру
- [x] Цифры можно показывать и над врагами, которым игра рисует свою полосу, без нашей полосы
- [x] Живой предпросмотр в меню показывает полосы такими, какими их нарисует игра
- [x] Поддержка героев, медведей и других контролируемых юнитов

# 单位血条
- [x] 显示敌方英雄的生命值和魔法值条
- [x] 仅在游戏隐藏原生血条时显示：身处迷雾、传送途中、被抛起或旋风时
- [x] 以游戏原生样式绘制，血条旁显示英雄头像与等级
- [x] 数字默认使用游戏原生的等宽数字字体，数值跳动时不会左右晃动；字体、大小、字重和描边均可自行设置，魔法条会增高以容纳数值
- [x] 每条状态条的数字可单独关闭：在分区标题处或点击预览即可
- [x] 数字也可显示在游戏保留原生血条的敌人上方，不绘制我们的状态条
- [x] 菜单中的实时预览按游戏的绘制方式显示状态条
- [x] 支持英雄、熊和其他可控单位
